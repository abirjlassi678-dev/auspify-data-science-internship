# Auspify Data Science Internship — Project Portfolio

## 📌 Overview
This repository contains my completed project work for the **Auspify Data Science Internship**. 
The project leverages Python and data science libraries to analyze, visualize, and model data from the Netflix Movies and TV Shows dataset.

---

## 🛠️ Tech Stack & Tools
- **Language**: Python
- **Environment**: Google Colab
- **Libraries**: Pandas, NumPy, Matplotlib, Seaborn, Scikit-Learn

---

## 📂 Completed Tasks Summary

### Task 1: Data Cleaning & Preparation
- Handled missing values, dropped unnecessary duplicate entries, and formatted dates.
- Output file: `netflix_cleaned.csv`

### Task 2: Exploratory Data Analysis (EDA)
- Visualized content distribution across Movies vs. TV Shows.
- Identified top content-producing countries and genre distributions.

### Task 3: Content-Based Recommendation System
- Built a recommendation model using Natural Language Processing (NLP).
- Utilized TF-IDF Vectorization and Cosine Similarity to recommend similar titles.

### Task 4: Trend Analysis & Growth Forecasting
- Analyzed historical trends in content release.
- Applied Linear Regression modeling to forecast Netflix content growth through 2030.
